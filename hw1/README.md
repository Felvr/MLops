# ДЗ1 — окружение, инференс Qwen3 и бенчмарк

Готовая работа: воспроизводимое окружение, первый инференс и раздельное измерение
загрузки модели, скорости генерации и пикового RSS.

Модель — `Qwen/Qwen3-0.6B`, устройство — CPU, тип весов — float32.
Условия, результаты и разбор четырёх исправленных дефектов находятся в
[docs/hardware.md](docs/hardware.md).

## Запуск

Выполняйте команды из папки `hw1/`:

```bash
uv sync --locked
make generate
make bench
make check
```

Первый запуск скачивает модель в кэш Hugging Face. Настройки модели и генерации
читаются из `params.yaml`, зависимости закреплены в `uv.lock`.
Для сохранённого эксперимента использовались Python 3.12 и Intel macOS.

`make bench` создаёт `docs/bench.json`; этот промежуточный файл исключён из Git.
Результаты сданного эксперимента сохранены в отчёте `docs/hardware.md`.
Окружение `.venv` и кэши создаются локально и также не публикуются.

## Репозиторий

Инструкция отправки всей ветки — в [корневом README](../README.md).

## Запуск после клонирования

Нужны Python ≥ 3.12, `uv`, Git и доступ к GitHub для первой загрузки источника.
Команды выполняются в `hw3/` внутри корневого Git-репозитория.

```bash
uv sync --locked
make repro
make check
make test
```

`download` загружает неизменяемый снимок источника с закреплённого commit SHA,
проверяет SHA-256, затем стадии `collect → clean → diversity → split → contamination`
строят датасет. Входной архив, происхождение каждой пары и все JSONL находятся
в игнорируемом `data/` и управляются DVC. Отдельный `.git` не нужен.

`collect` выбирает раздел GHR, оставляет четыре типа содержательных вопросов,
нормализует пробелы, добавляет четыре варианта системной инструкции и записывает
происхождение строк в `data/provenance.jsonl`. Медицинские ответы не генерируются
и не переводятся. Клиническая корректность старого источника вручную не проверена.

## Версии и DVC

```bash
make v1        # 400 исходных документов
make v2        # расширение до 650 документов
make diff      # dvc metrics diff hw3-v1 hw3-v2
uv run dvc push
```

Git-теги `hw3-v1` и `hw3-v2` фиксируют конфигурации, хэши данных и метрики.
Данные находятся в локальном DVC remote `../.local/hw3-dvc-remote`, который
**не отправляется на GitHub**. На другом компьютере используйте `make repro`:
исходник скачается заново. Для обмена кэшем отдельно скопируйте remote либо
настройте общее DVC-хранилище. Пайплайн может восстановить обе версии без remote.

```bash
make diversity       # гейт качества всего набора
make contamination   # проверка всех трёх пар сплитов
make dag
```

Пороги разнообразия сохранены из задания. Near-dup использует точный Жаккар
словных 4-грамм с полным обратным индексом, порог 0.85 одинаков для очистки
и контаминации. Это лексическая проверка, а не гарантия отсутствия семантических
парафразов. `num_perm` оставлен для совместимости с интерфейсом заготовки и
не используется точным алгоритмом.

## Проверки и сдача

`make check` выполняет все восемь проверок курса, включая искусственные дубли,
ПДн, битую строку и вырожденный набор. Критерии исходного скрипта сохранены;
добавлена проверка кодов выхода `dvc repro` и восстановление параметров при сбое.
`make test` дополняет их регрессиями Жаккара, перестановки вариантов, устойчивости
сплита при расширении данных и маскирования ПДн на русском и английском.

Видео — визуализация записанного вывода настоящего `make check` с исходным
временем событий. Журнал позволяет проверить результат текстом.

Отправка из корня проекта (после проверки изменений):

```bash
git push -u origin MLops
git push origin hw3-v1 hw3-v2
```

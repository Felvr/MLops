# ДЗ5 — LoRA на собственном MedQuAD

**Статус:** окружение и код подготовлены и проверены небольшими тестами.
Обучение и итоговую проверку вы запускаете самостоятельно. Итоговых
кривых, замеров качества и девяти зелёных проверок ещё нет.

По умолчанию включён **быстрый эксперимент** для Intel Mac с 16 ГБ памяти:
32 обучающих и 8 проверочных примеров из собственных тензоров ДЗ4,
два варианта LoRA по 8 шагов. В обоих сплитах отбираются целые примеры
длиной до 256 токенов. Ориентир для всего запуска вместе с `make check` —
**15–25 минут** по предыдущим коротким замерам. Это оценка с запасом,
а не гарантированный предел: фоновая нагрузка и нагрев могут замедлить Mac.

Базовая модель — `Qwen/Qwen3-0.6B`, revision
`c1899de289a04d12100db370d81485cdf75e47ca`. Задача — англоязычные ответы
о генетических заболеваниях из MedQuAD (GHR).

## Личный запуск

Откройте терминал. Подключите Mac к питанию и выполните:

```bash
cd /Users/revyak/Documents/ChatGPT/MLops/hw5
uv sync --locked
make prepare
make test
set -o pipefail
make repro 2>&1 | tee docs/repro.log
make report 2>&1 | tee docs/report.log
make check 2>&1 | tee docs/check.log
```

Выполняйте команды по очереди, переходя к следующей после успешного завершения.
`make repro` сам запускает оба обучения, сравнение и построение графика,
записывает `dvc.lock` и не повторяет неизменившиеся стадии при новом запуске.
Если `uv` не найден, добавьте его в текущую сессию командой
`export PATH="$HOME/.local/bin:$PATH"`.

После `make prepare` в [docs/data.md](docs/data.md) должны быть **32 train и
8 val**. Там же записаны выбранные ID и хеши. После `make repro` появятся
`docs/curves.png`, `docs/compare.md`, два каталога адаптеров и метрики.
`make report` заполнит `docs/defects.md` числами из этих метрик.
`make check` дополнительно выполнит два обучения по три шага и загрузит копию
адаптера офлайн. Снимите видео с финальной строкой `Все проверки пройдены`
и отпечатком `06a02208c1f0`, сохраните как `docs/check.mp4`.

После запуска обратитесь ко мне: я проверю `docs/repro.log`, `docs/check.log`,
`docs/curves.png`, `docs/compare.md`, `docs/defects.md` и локальные
`metrics/train_*.json`. На этой машине я смогу прочитать их непосредственно
из папки проекта. До проверки результатов работа не объявляется готовой к сдаче.

## Как устроен быстрый режим

`params.yaml` — единственная точка конфигурации:

```yaml
data:
  subset:
    enabled: true
    train_size: 32
    val_size: 8
    max_example_tokens: 256
    seed: 42
train:
  batch_size: 1
  grad_accum: 4
  epochs: 1
  max_steps: 8
  eval_every: 4
```

Исходные `../hw4/data/tokenized/train.pt` и `val.pt` сохраняются.
`make prepare` выбирает примеры отдельно внутри каждого исходного сплита:
сначала фильтр длины, затем сортировка по SHA-256 от `seed:id`.
Отбор фиксирован до обучения, одинаков для обоих вариантов и не использует
лосс или ответы модели. Последовательности токенов, labels и attention mask
выбранных примеров не изменяются. Повторная токенизация не выполняется.

Для одного варианта 32 примера дают 8 шагов при эффективном батче 4.
Val loss считается на тех же 8 отложенных примерах на шагах 0, 4 и 8.
Первый вариант содержит LoRA на слоях 0–27, второй — на слоях 14–27.
База и адаптер сравниваются на пяти заранее выбранных вопросах исходного val,
по 40 новых токенов. [Происхождение вопросов](docs/prompts.md).
Системная инструкция совпадает с ДЗ4, декодирование жадное.

Малый набор коротких ответов меняет распределение данных. Он позволяет
быстро проверить пайплайн, но не даёт надёжной оценки качества модели на всём
MedQuAD. Сходимость и прохождение проверки 2 нужно подтвердить реальным
запуском; уменьшение датасета их не гарантирует. Сокращённый режим отражается
в метаданных тензоров, метриках и отчёте; его согласование преподавателем
не подтверждено.

## Полный набор

Чтобы вернуться ко всем 1972 train и 266 val примерам, измените:

```yaml
data:
  subset:
    enabled: false
train:
  grad_accum: 8
  max_steps: null
  eval_every: 10
```

Затем выполните `make repro`, `make report` и `make check`.
Стадия prepare восстановит точные копии тензоров ДЗ4, затем DVC пересчитает
изменившиеся стадии. Полная эпоха при эффективном батче 8 содержит 247 шагов;
на этом Mac такой запуск может занять сутки и более.
Не меняйте код или параметры во время обучения.

Если исходных тензоров ДЗ4 нет, восстановите данные ДЗ3 и выполните `make repro`
в ДЗ4 по [его инструкции](../hw4/README.md).

## Окружение и файлы

На этом Intel Mac выбраны CPU, float32, 8 потоков и батч 1.
Gradient checkpointing выключен; при нехватке памяти включите его,
учитывая увеличение времени. Зависимости зафиксированы в `uv.lock`:
PyTorch 2.2.2 для Intel macOS, 2.5.1 для остальных платформ,
NumPy 1.26.4, Transformers 4.56.2 и PEFT 0.14.0.
Повторяемость проверяется на одном железе и в одном окружении.

`tests/check.sh` сохранён без изменений, SHA-256 начинается с **06a02208c1f0**.
В Git входят код, конфигурация, lock-файлы, отчёты, график и видео.
Данные, адаптеры, окружение и сырые JSON-метрики исключены из Git.
DVC cache локален, опубликованного хранилища весов у этой работы нет.
Git-команды выполняются из корня `MLops`.

Команды `make train` и `make compare` также доступны для отдельных запусков;
после изменения режима сначала выполните `make prepare`. Код проверяет,
что подготовленные данные соответствуют выбранному режиму.
`make clean` удаляет выходы обучения, `make distclean` — также окружение.

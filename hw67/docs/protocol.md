# Протокол, закреплённый до генерации

База: Qwen/Qwen3-0.6B, c1899de289a04d12100db370d81485cdf75e47ca.
CPU float32, seed 42. Шесть конфигураций из params.yaml получают один
бюджет: 4 шага, train 32, val 8, batch 1, accumulation 2. Данные ДЗ5
сохранены побайтово, каждый пример сверяется с ДЗ4. Кандидат выбирается
только по val loss, при val/base <= 1. Test не используется в sweep.

Задача golden — выбрать утверждение, непосредственно подтверждённое
выдержкой MedQuAD. Это проверка чтения источника, а не диагностика пациента
и не независимый экзамен медицинских знаний. Вопросы составлены для этой
работы: 50 разных выдержек, по три варианта, позиция верного ответа меняется.
Правильный вариант совпадает с первым предложением выдержки, два других
взяты из других документов и содержат конкретные гены, не упомянутые
в данной выдержке; общие фразы «редкое заболевание, частота неизвестна»
не используются как отвлекающие варианты. Это намеренно простой тест; он может решаться
по совпадению фрагментов и не измеряет сложное медицинское рассуждение.
Оригинальные ответы, разметка, URL и ревизии — в annotation-audit.jsonl.
Имена болезней редактируются, но аббревиатуры могут оставаться; эталон
определяется поддержкой утверждения данным текстом, а не угадыванием имени.

Источник — ранее отложенные темы MedQuAD из test ДЗ3, отсутствующие во всём
исходном train, не только в коротком пуле 32. Эта часть отложенного набора
становится golden для решения о выпуске; отдельным независимым test после
такого использования её считать нельзя. Автопроверка ищет точные совпадения
и пересечение тем; отсутствие смысловых утечек этим не доказано.

Срезы по типу исходной выдержки: information (17), frequency (17),
genetic_changes (16). Они проверяют описания, частоты и генетические механизмы.
Критические — information и genetic_changes: неверное чтение описания
болезни и смешение генетических механизмов особенно нежелательны.
Срезы не пересекаются. Полный train-index содержит все исходные вопросы train.

Обе версии получают один system из evaluation/params.json, без expected
и source, greedy decoding, seed 42, максимум 16 новых токенов.
Строго принимается только JSON с единственным строковым answer из choices.
Невалидный ответ и ошибка остаются в знаменателе. Никакой нормализации,
извлечения JSON из пояснений и повторных попыток ради улучшения метрики нет.

Behavioral: обязательный JSON, перефраз вопроса с тем же group_id,
отказ REFUSE для рецепта торта вне темы. Эти три случая не входят в n=50.
Accuracy и format rate должны быть не ниже baseline; accuracy критических
срезов не должна падать; все behavioral должны пройти. Допуск регрессии 0.
Missing, NaN, несовместимость и ошибки генерации запрещают выпуск.
Изменение протокола требует новой оценки обеих версий, а не правки метрик.

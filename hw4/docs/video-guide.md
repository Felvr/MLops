# Как записать видео ДЗ4

Записывайте окно терминала крупным шрифтом. Окружение и данные на этом
компьютере уже подготовлены. Интернет может потребоваться для проверки
токенизатора; веса модели не скачиваются.

## 1. Начало — 20–30 секунд

Скажите: «В ДЗ4 я подготовил свой датасет MedQuAD из ДЗ3 для обучения.
Это 1972 обучающих и 266 проверочных диалогов. Здесь используется только
токенизатор Qwen3-0.6B».

Откройте терминал в `MLops` и выполните:

```bash
cd hw4
make check
```

Дождитесь окончания: проверка несколько раз обращается к токенизатору.
При необходимости прокрутите вывод и покажите проверки 1–9.

## 2. Обязательный финальный кадр

В кадре должны быть одновременно видны:

- `отпечаток tests/check.sh: f2002c8c9519`;
- `Все проверки пройдены.`

Задержите кадр на несколько секунд. Скрипт проверки не редактировался.

## 3. Краткий разбор — 1–2 минуты

Откройте `docs/defects.md` и `docs/tokenize_report.md`.

1. Маска: промпт получает −100. Под лоссом 380951 из 477798 токенов train;
   декодирование этих позиций даёт только ответ. Доля ответа здесь выше,
   чем в лекции, потому что медицинские ответы длинные.
2. Шаблон: обучение и инференс используют `src/prompt.py`;
   промпт инференса — точный префикс полного диалога.
3. Паддинг: добавляется слева до самой длинной строки батча;
   маска внимания на нём нулевая, метки −100.
4. Обрезка: при 232 токенах терялись хвосты почти половины ответов.
   При 768 — 0,35% train и 1,13% val, оба ниже 5%.

При желании покажите `make test`: восемь дополнительных тестов пограничных
случаев. Завершите словами: «Данные и тензоры в Git не входят, отчёты и
версии зависимостей сохранены; прогноз времени — оценка по ДЗ1,
обучение будет проверяться отдельно».

Видео не создано автоматически: это инструкция для самостоятельной записи.

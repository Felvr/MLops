Исправлены четыре дефекта выданной заготовки. Вход — собственные сплиты

токенизатор Qwen3-0.6B; веса модели и обучение не требуются.

## На этом компьютере

Из корня `MLops`:

```bash
cd hw4
uv sync --locked
make repro
make check
make test
```

Для видео достаточно `make check`: он заново запускает токенизацию,
показывает все девять результатов и отпечаток **f2002c8c9519**.
Скрипт преподавателя сохранён без изменений. Видео записывается отдельно.

## После клонирования

Нужны Git, `uv` и Python 3.12 (uv может установить Python).
Сначала восстановите исходные данные ДЗ3 из закреплённого снимка источника:

```bash
cd hw3
uv sync --locked
make repro
cd ../hw4
uv sync --locked
make repro
make check
make test
```

Первый запуск требует доступа к GitHub, PyPI и Hugging Face. DVC и Python
зависимости устанавливаются из lock-файлов. Для Intel macOS закреплены
PyTorch 2.2.2 и NumPy 1.26.4, для остальных платформ — PyTorch 2.5.1.
Система воспроизведения проверена на Intel macOS / Python 3.12.

В `hw4` находится отдельный DVC-проект внутри общего Git-репозитория;
вложенного `.git` нет. Удалённое DVC-хранилище для ДЗ4 не требуется:
данные восстанавливаются из ДЗ3, токены — из данных и закреплённого токенизатора.
DVC-кэш локальный и на GitHub не отправляется.

## Что делает пайплайн

1. `prepare` копирует train/val из ДЗ3 без изменений и сохраняет SHA-256.
2. `tokenize` строит общий шаблон, маскирует промпт, обрезает хвост и сохраняет
   `data/tokenized/train.pt`, `val.pt`, JSON-метрики и Markdown-отчёт.
3. `lengths` сравнивает потери при разных лимитах и пишет `metrics/length_sweep.json`.

При лимите 768 обрезано 0,35% train и 1,13% val; порог 5% сохранён.
В train под лоссом 380951 из 477798 токенов. На паддинге и промпте метки
равны −100, паддинг динамический слева. Данные — английские медицинские QA,
поэтому доли токенов отличаются от русскоязычного примера лекции.

Packing не включён: подготовлен обычный датасет независимых примеров.
Для его включения понадобился бы отдельный путь обучения с блочной маской
внимания. `src/prompt.py` общий для обучения и будущего инференса, в том числе
для списка сообщений без готового ответа ассистента.

`make prepare`, `make tokenize` и `uv run python -m scripts.analyze_lengths`
позволяют выполнить отдельные операции. После изменений кода или параметров
используйте `make repro`, чтобы обновить DVC lock и все отчёты.
`make clean` удаляет только подготовленные `.pt`, сохраняя исходные JSONL.

## Публикация

Код, отчёты, метрики, `uv.lock` и `dvc.lock` входят в Git. JSONL, `.pt`,
окружение и кэши исключены. Работа публикуется вместе с остальными ДЗ
из корня `MLops` командой `git push -u origin MLops`.

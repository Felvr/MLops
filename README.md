# MLOps — домашние работы

Один репозиторий, ветка `MLops`. Каждая готовая работа находится в своей папке.

Правила структуры и выполнения следующих ДЗ закреплены в [agent.md](agent.md).

| Работа | Содержание | Отчёт |
|---|---|---|
| [ДЗ1](hw1/README.md) | Окружение, инференс Qwen3 и бенчмарк | [hardware.md](hw1/docs/hardware.md) |
| [ДЗ2](hw2/README.md) | Параметры модели, хуки, LoRA и память | [anatomy.md](hw2/docs/anatomy.md) |

## Запуск

Команды выполняются из папки соответствующей работы. Каждая работа имеет свой
`pyproject.toml`, `uv.lock`, `params.yaml` и локальное окружение `.venv`.

```bash
cd hw1
uv sync --locked
make check
```

Для второй работы:

```bash
cd hw2
uv sync --locked
make check
```

Подробные команды и условия экспериментов приведены в README каждой работы.

## Структура и новые работы

В Git включаются `hw1/`, `hw2/` и будущие папки `hw3/` … `hw999/`, а также этот
README, `agent.md`, `AGENTS.md` и корневые настройки Git. Внутри работ хранятся код, конфигурация,
зафиксированные зависимости, проверки и материалы, необходимые для сдачи.

Лекции, исходные папки `*-broken`, архивы, резервные копии и прочие файлы в корне
остаются локальными: корневой `.gitignore` исключает их по умолчанию.
Окружения, кэши Python и служебные файлы также исключены внутри папок ДЗ.
Не создавайте вложенные `.git` в новых работах.

## Отправка на GitHub

Корневой `origin` указывает на `https://github.com/Felvr/MLops.git`.
Все работы отправляются одной веткой из корня проекта:

```bash
git switch MLops
git push -u origin MLops
```

Команда отправляет ветку `MLops`; существующая ветка `master` остаётся отдельной.
